# Landing Page Barbearia

Landing page estática para apresentação de uma barbearia, com contato, localização e CTA direto para WhatsApp.

## Dados editáveis

Antes de publicar, substitua no `index.html`:

- Nome da barbearia: `Barbearia Corte Nobre`
- WhatsApp: `5511999999999`
- Telefone: `(11) 99999-9999`
- Endereço: `Rua dos Andradas, 240 - Centro, São Paulo - SP`
- Link do mapa

## Comandos

```bash
npm install
npm run dev
npm run check
npm test
npm run build
```
